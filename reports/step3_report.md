# Step 3 report: solver validation

Generated by `uv run validate.py`. Solver: `lbm.py`, sparse D3Q27 lattice Boltzmann on the GPU with NVIDIA Warp: regularised collision with a Galilean-invariance correction, interpolated (Bouzidi) walls from the signed distance, equilibrium velocity inlet and pressure outlets at any orientation, thin sponge layers (tau up to 0.55) inside the open ends. All tests use blood's real viscosity at the artery's grid spacing and time step (tau ~ 0.502-0.505), where lattice-Boltzmann schemes are least forgiving.

## 0. How the solver was chosen (development runs, 20-40 cells across, blood viscosity)

| finding | consequence |
|---|---|
| D3Q19: in a straight pipe, spurious secondary vortices once the grid Reynolds number u dx / nu exceeds ~30 (velocity error 0.8 % -> 6-10 %); D3Q27: none up to 73 (White & Chong 2011 report the same) | D3Q27 |
| two-relaxation-time (TRT) collision: blows up at the velocity inlet within ~3000 steps; with sponges stable but loses ~5 % of the flow over 12 diameters in a pipe tilted to the grid (interpolated walls are not mass-conserving with its slow odd-moment relaxation) | regularised collision (0.4 % loss) |
| bounce-back inlet: imposes a profile ~6 % too peaked, which takes ~15 diameters to relax | equilibrium inlet cells |
| regularised collision near tau = 1/2: walls sit slightly inside (velocity -3.4 % at 20 cells, -0.9 % at 40, 2nd order) | accepted; documented below |

Operating point (healthy): dx 0.1 mm, dt 5 us, lattice viscosity 1.65e-03, tau 0.50495; 1 m/s = 0.050 lattice units.
